Lenarchain is a blockchain built with a focus on scalability, simplicity, and practical use.

<Warning>
  The project is in an early stage and currently runs as a mainnet alpha: a lightweight chain that supports transfers only. This documentation covers the basics. More details will be released before the full launch, which is scheduled after the early supporter phase. They include the instruction set model, the full RPC API, and the consensus model.
</Warning>

## Source code

Our open-source code, including the wallet, is available on [GitHub](https://github.com/lenarchain).

## Conventions

- All RPC examples use Python with the `requests` library.
- Signing examples also use `pycryptodome` and `pynacl`. See [Transactions](/concepts/transactions).
- The examples use a node running at `https://alpha.lenarchain.xyz`.
- Large integers are returned as decimal strings. See the [RPC overview](/rpc/overview#number-format).
